# Portland Design Lab — Pilot Build Plan

Status: DRAFT v1 · 2026-09-11 · Owner: Dave (decision) / Brian (ops) / Hal (design/structure)

## Locked decisions (Dave, 2026-09-11)
1. **Pilot first** — small compressed run to validate logistics before any full-scale event.
2. **Both cohorts** — parallel adult and youth (citizen-designer) tracks.
3. **Portland orgs = potential partners** (network, not competition).

## Core positioning (Hal + Brian, confirmed)
Not another discipline-based festival (Design Month / ADX already own that).
Gap = **experience + methodology**: curated mixed-disciplinary cohorts who go
inside real design environments, experience how design happens, then participate
in a real Portland design challenge → observe → prototype → critique → present.

## Pilot target
- **Window:** Tue 2027-02-09 → Thu 2027-02-11 (3 days, compressed arc).
  - Avoids Oct 2026 congestion; lands beside Portland Winter Light Festival (Feb 6–14 2027) as a possible touchpoint.
  - Fallback window: early Apr 2027 if Winter Light adjacency is unwanted.
- **Size:** 2–4 cross-disciplinary teams; adult cohort (~8–16 ppl) + youth cohort (~8–16, with teacher/mentor support). Given the holidays, do NOT depend on Oct/Nov June staffing.
- **Format (3-day arc):** D1 big-picture + context → D2 field observation + build → D3 present + critique (+ public/parent/community showcase).
